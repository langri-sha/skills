# Failures

Symptom, cause, what the verb does, and what to tell the user.

| Symptom                                                                                 | Cause                                                                                                                              | What the verb does                                                                   | Tell the user                                                                                                                     |
| --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `seat` exits 4 with `HC_TERMINAL_ID` or `HERDR_PANE_ID` set                             | The variables are inherited from a launcher whose terminal is not this process's tty, as in a job started elsewhere                | Ignores the variables, since the tty decides, and reports `no_seat`                  | This agent is not in a Herdr terminal of its own; ask which terminal to use                                                       |
| `seat` reports `backend: tmux`                                                          | tmux runs inside Herdr, and the tty belongs to the tmux pane                                                                       | Reports the tmux pane; the other verbs exit 4                                        | Say it is a tmux seat; Herdr verbs do not apply                                                                                   |
| `session_match: false`, `background_job: true`                                          | The terminal's recorded session is not this process's: a background job holding an inherited address, or a continued session       | Reports both and changes nothing                                                     | Ask which terminal is yours before placing anything beside it                                                                     |
| `session_match: null`                                                                   | The machine labels no sessions on terminals, or `CLAUDE_CODE_SESSION_ID` is unset                                                  | Reports `session_reason`                                                             | Nothing, unless identity matters: then name the terminal explicitly                                                               |
| `whois` lists an entry in `degraded`                                                    | The terminal has no `claude.session` label                                                                                         | Reads the agent process's flags and its own session record, then its `--resume` flag | The session came from the process tree; say so when you quote it                                                                  |
| `whois` has `session: null`                                                             | No label, no session record, no `--resume` flag, as with a fresh Codex                                                             | Returns `resume: null`                                                               | The session cannot be resumed from here                                                                                           |
| `read` returns `screen_only: true`                                                      | `hc` serves only the screen while the agent works                                                                                  | Waits once for it to stop, reads again, and reports `waited: true`                   | The history is not available while it works; read again when it is idle                                                           |
| `read` returns `fallback: "visible"` (TUI)                                              | The TUI cannot scroll an alternate screen while the agent works, and answers `agent_not_idle`                                      | Reads the visible screen instead                                                     | Only the visible screen is shown                                                                                                  |
| `read` or `whois` exits 3                                                               | No such terminal, pane or agent: it ended, or the name was never registered                                                        | Reports `not_found` and the failing command                                          | Run `roster` to find it                                                                                                           |
| `roster` shows `bypass: false` for a Claude agent                                       | It started without the permission flag; nothing inherits it, so the settings default applies                                       | Reports the footer's mode in `permission_mode`                                       | The agent needs a relaunch with the flag; that is the user's call                                                                 |
| `roster` shows `bypass: null`                                                           | A dialog hides the footer, the agent is Codex (its footer is not matched), or the footer could not be read                         | Leaves it unknown instead of guessing                                                | Check `dialog` first, then read the terminal                                                                                      |
| `roster` shows `status: blocked` and a `dialog`                                         | The agent waits on a permission or a question                                                                                      | Returns the dialog's `kind` and `msg`                                                | Show the dialog and ask; a permission decision is never yours to make                                                             |
| `seat` has `space.id` and `tab.id` from labels, not the window                          | The app window is closed, so `herdr-app ls` failed                                                                                 | Falls back to the `herdr.space`, `herdr.tab` and `where` labels                      | Nothing, unless the ids are missing: then ask the user to open the window                                                         |
| `space` exits 5                                                                         | A space or workspace of that name is already open                                                                                  | Opens nothing and lists the `existing` ones                                          | Ask whether to reuse it or pick another name                                                                                      |
| `launch` exits 6 `launcher_failed` with a line such as `authorization prompt dismissed` | The shell function asked the user to approve the launch and the approval was dismissed or timed out; a burst of launches does this | Stops at the first matching line and never retries                                   | Give the user the exact `command` to run themselves, or wait for them; do not retry in a loop                                     |
| `launch` exits 6 `shell_returned`                                                       | The command failed and the shell prompt came back, as when the program is not installed                                            | Reports the screen's last lines in `footer`                                          | Show the footer; the launch line did not start an agent                                                                           |
| `launch` exits 7 `timeout`                                                              | The agent is not idle with the right permission footer, or an approval is still pending                                            | Reports `status`, `permission_mode` and `model_shown`                                | Say which is missing; a `permission_mode` other than the expected one means the flag did not take. `model_shown` is only reported |
| `launch` or `deliver` exits 9 `blocked`                                                 | A dialog is open, such as folder trust, a sign-in or a permission prompt                                                           | Returns the dialog's `kind`, `msg` and `options` and sends nothing                   | Show the dialog and ask; only the folder-trust dialog may be answered, through `dialog --answer`                                  |
| `launch` exits 8 `not_idle_shell`                                                       | The terminal's shell runs a program, or the terminal is not a shell                                                                | Refuses before typing anything, naming the program                                   | Pick another terminal or end the program first                                                                                    |
| `launch` exits 8 `reported_shell`                                                       | The terminal once reported an agent status, so `hc` wraps typed text in tags that bash cannot run                                  | Refuses before typing anything                                                       | Launch into a new terminal with `--space` and `--tab`                                                                             |
| `launch` exits 11 or `deliver` exits 11                                                 | The terminal ended                                                                                                                 | Reports `finished`                                                                   | Start a new terminal                                                                                                              |
| `deliver` exits 10 `unconfirmed`                                                        | The text went in but the agent did not start working in time, or the program reports no status                                     | Reads the screen into `screen` and sends nothing more                                | It may have arrived; read the screen before sending again, never resend blindly                                                   |
| `dialog --answer` exits 9 `not_allowed`                                                 | The dialog is not the folder-trust dialog, or it is a tool-permission prompt                                                       | Presses nothing and returns the dialog                                               | Show the dialog and ask                                                                                                           |
| `dialog --answer` exits 8 `no_dialog`                                                   | The terminal is not blocked                                                                                                        | Presses nothing                                                                      | Nothing; the dialog is already gone                                                                                               |
