---
name: bell
description: >-
  Plays a bell sound, or the terminal bell where no player is installed, to get
  the user's attention right away. Use when the user asks for a bell or a sound.
  Not for announcing that a task is done (notify-me).
---

When the user invokes `/bell`, play a bell sound immediately.

## How to play the bell

Run `bell.sh`, where `<skill-dir>` is the directory holding this file:

```bash
bash <skill-dir>/bell.sh
```
